# Roadmap

Principle: one reliable end-to-end experience beats ten disconnected features.

- **M1 Foundation (done)** — KMP project (Android + desktop), deterministic cash engine,
  comparison, tests incl. verified UBS golden values, minimal shared UI.
- **M2 Financial intelligence** — Guardian risks, intervention windows, Skeptic sensitivity,
  Explorer counterfactuals; tests for each.
- **M3 Android UX** — story onboarding, profile confirmation, scenario selection,
  perspective selection, plain-language explanations.
- **M4 Desktop exploration** — timeline, comparison charts, risk/assumption panels,
  calculation inspector (per-month `MonthRecord`), references for external rules.
- **M5 Wow** — perspective mixer (prioritises analyses, never changes numbers), LLM
  orchestration that only calls core and narrates its outputs, optional voice, clearly
  labelled hypothetical storytelling, session handoff.
- **M6 Validation & pitch** — correctness audit, edge cases, smoke tests, demo rehearsal +
  backup recording, JetBrains shared-code story, IMC social-impact story.

Out of scope for now: real banking/data, auth, payments, trading, tax/loan engines,
unsourced benefits rules, market feeds, generic chatbot, agent frameworks, backend, sync,
PDF export, avatars, 3D.
